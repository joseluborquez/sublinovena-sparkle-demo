# Instrucciones para Claude Code

- No uses las herramientas de Claude in Chrome (navegador) salvo que el usuario lo pida explícitamente en ese momento. El usuario prefiere revisar los cambios él mismo en su propio localhost (`http://localhost:8081/`) antes de que se verifique nada por browser automation.
- Nunca hagas `git commit` ni `git push` sin la aprobación explícita del usuario en el chat (ver también `.claude/skills/commit-approval/SKILL.md`). El usuario revisa los cambios en su localhost antes de aprobar.
